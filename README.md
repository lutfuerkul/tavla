# Tavla

Three.js ile hazırlanmış, birinci şahıs kameradan görüntülenen 3B tavla masası.

## Çalıştırma

Bu depo statik bir web uygulamasıdır. Yerel bir HTTP sunucusuyla açın:

```bash
npx serve .
```

Ardından tarayıcıda gösterilen yerel adresi açın ve **Masaya otur** düğmesine basın.

## İlk sürüm

- Birinci şahıs fare kontrolü
- Ahşap çerçeveli, keçe yüzeyli 3B tavla tahtası
- Siyah ve kemik rengi taşlar
- Metal ayrıntılar, gölgeler ve sinematik aydınlatma
- Zarlar ve oyun durumu göstergesi

Sonraki adım: taş seçimi, yasal hamleler, zar atma ve oyun kuralları.
